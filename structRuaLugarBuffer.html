Descrição detalhada

Estrutura temporária para acumulação de dados de um "way" OSM durante o parsing SAX, antes de sua inserção definitiva no mapa.

Um "way" no formato OSM representa uma via (rua, avenida, etc.) composta por uma sequência ordenada de nós. Esta struct armazena os campos relevantes
