bool MapGenerator::nome_arquivo_valido ( const std::string &  path)
private

‪Verifica se o nome (caminho) do arquivo é válido para processamento.

O nome não pode ser vazio, deve terminar com ".osm" e o nome base (sem extensão) deve conter apenas caracteres alfanuméricos, underscores, hífens ou pontos.

Parâmetros
path‪Caminho do arquivo a ser verificado.
Retorna
‪true se o nome do arquivo for considerado válido, false caso contrário.
Observação
‪Esta função é case-sensitive e não aceita extensões alternativas (ex: ".OSM").
